    Type Alias HealthRecord

    One extensible record stored by the Voltra Health subsystem.

    The model intentionally keeps one driver-backed shape for telemetry, findings, repairs, checkpoints, run state, and queued work. Additional structured detail belongs in data rather than separate storage models.
