# Compiled Learnings

1. Get today's date
2. Make a folder in planning called `learnings`
3. Make a folder in planning called `archived`
4. Make a new learnings `.md` file in `learnings` with the date in the file name
5. Look through all of the current plans in the `planning/complete` folder and condense and compile all learnings from
   those files into the new learnings file
6. Learnings files should not just be a bunch of files thrown into one
7. Learnings files should be refined, condensed learning presented in a way that is easy to digest and gain deep insight
   from
8. Once the new learnings file is done, move all plans from `planning/complete` into `planning/archived`
9. Document this process in `AGENTS.md`, making agents aware of the process and where to find valuable learnings about
   this project
10. This process should only be done upon request
